# HEDIMA — Site officiel

Site vitrine de Hedima, accompagnement et gestion de patrimoine immobilier à Cocody, Abidjan.

## Démarrage
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Identité
Charte officielle : bleu Hedima `#0C466E`, or cauri `#D9A441`, sable, crème. Typographie Montserrat. Logo officiel dans `public/logo/Logo.png`.

Les photographies sont des visuels illustratifs, en attendant les images officielles de Hedima.
